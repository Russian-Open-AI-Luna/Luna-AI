# Ornit
это нейросеть на базе локальной Qwen-Coder все остальное сделано полностью с нуля 
есть 4 семейства:
Moon - флагман
Sky - старший
Feather - средний
Song - младший
## Версирование Moon

Moon движется так: **любое число → любое число.1 → любое число.3 → любое число.5 → любое число.8 → и всё повторяется**.

Например: 2 → 2.1 → 2.3 → 2.5 → 2.8 → 3 → 3.1 → 3.3 → 3.5 → 3.8 → 4 …

## Версирование Sky

Sky движется так: **любое число → любое число.2 → любое число.4 → любое число.7 → любое число.9 → и всё повторяется**.

Например: 2 → 2.2 → 2.4 → 2.7 → 2.9 → 3 → 3.2 → 3.4 → 3.7 → 3.9 → 4 …

## Версирование Feather

Eclipse движется так: **любое число → любое число.5 → любое число.6 → любое число.8 → и всё повторяется**.

Например: 2 → 2.5 → 2.6 → 2.8 → 3 → 3.5 → 3.6 → 3.8 → 4 …

## Версирование Song

Song движется так: **любое число → любое число.8 → и всё повторяется**.

Например: 2 → 2.8 → 3 → 3.8 → 4 → 4.8 …
